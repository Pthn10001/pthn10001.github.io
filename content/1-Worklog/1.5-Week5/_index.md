### Week 5 Objectives:

* Gain a solid understanding of AWS database services such as Amazon RDS, Aurora, Redshift, and ElastiCache.
* Understand and practice deploying a Static Website with Amazon S3 and improving access performance using CloudFront.
* Practice basic operations with Amazon RDS, including database creation, application deployment, backup, and restore.
* Understand and implement EC2 Auto Scaling combined with a Load Balancer to scale applications.
* Continue researching the group project and complete the proposal.
