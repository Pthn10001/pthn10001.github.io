### Week 8 Objectives:

* Master building and managing infrastructure using the AWS Cloud Development Kit (AWS CDK).
* Understand and practice deploying applications on AWS using Infrastructure as Code with AWS CloudFormation and AWS CDK.
* Build and deploy a Serverless backend using AWS Lambda, Amazon S3, and Amazon DynamoDB.
* Understand the process of developing a frontend integrated with Serverless APIs through Amazon API Gateway and AWS Lambda.
* Strengthen skills in deploying and managing modern application architectures on AWS.

### Week 8 Achievements:

* **Mastering AWS CDK:** Achieved proficiency in defining cloud infrastructure using familiar programming languages (CDK). Effortlessly deployed complex environments containing ECS, ALBs, and Nested Stacks without relying solely on JSON/YAML templates.
* **Three-Tier Architecture:** Utilized IaC principles to successfully provision a classic 3-tier application model (Web, App, DB), ensuring robust security and isolated network traffic flows.
* **Full-Stack Serverless:** Packaged an End-to-End serverless project: connecting a frontend to API Gateway, utilizing backend Lambda functions for business logic, and persisting data securely on DynamoDB.
* **Final Presentation Readiness:** Consolidated comprehensive knowledge, hands-on experience, and functional prototypes, fully prepared for the final Capstone project presentation.
