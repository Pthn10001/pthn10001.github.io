### Week 6 Objectives:

* Master the Serverless architecture on AWS using AWS Lambda and related services.
* Understand and practice building a Serverless backend with AWS Lambda, Amazon S3, and Amazon DynamoDB.
* Become proficient in using AWS CLI to manage and automate AWS resources.
* Learn and deploy Amazon ElastiCache to improve application performance through in-memory caching.
* Strengthen automation, infrastructure management, and AWS operations skills.

### Week 6 Achievements:

* **Serverless Architecture:** Developed AWS Lambda functions to automate infrastructure tasks (scheduled EC2 Start/Stop) and integrated real-time webhook alerts into Slack.
* **Serverless Backend Construction:** Orchestrated seamless workflows between Amazon S3, AWS Lambda, and DynamoDB to build an automated, serverless image processing and metadata logging pipeline.
* **Command Line Proficiency (AWS CLI):** Elevated system administration skills by managing IAM, VPCs, S3, and EC2 instances entirely through the command-line interface.
* **Application Acceleration:** Deployed and configured Amazon ElastiCache clusters (in both enabled and disabled Cluster Modes), gaining deep insights into in-memory caching mechanics.
