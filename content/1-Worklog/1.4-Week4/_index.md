### Week 4 Objectives:

* Master the process of launching, configuring, and managing Amazon EC2 instances on both Windows and Linux.
* Become proficient in EC2 administration, including Snapshots, AMIs, access recovery, and Node.js application deployment.
* Understand and apply IAM to manage access permissions and control AWS resources.
* Consolidate knowledge of AWS storage services, including Amazon S3, Glacier, Storage Gateway, and Backup.
* Gain a solid understanding of core AWS security services while continuing the group project research.

### Week 4 Achievements:

* **Practical EC2 Administration:** Mastered launching instances, baking Custom AMIs, managing Snapshots, and recovering lost access keys across both Windows and Linux environments.
* **Application Deployment:** Successfully provisioned server environments (LAMP/XAMPP) and deployed a functional Node.js web application on EC2.
* **Resource Governance (IAM):** Gained proficiency in writing IAM Policies to tighten security, such as restricting resource creation by region or instance type, and preventing accidental deletion.
* **Storage & Security Acumen:** Understood the mechanics of AWS storage solutions (S3, Glacier, Storage Gateway) and advanced security services (KMS, Cognito, Security Hub).
* **Project Milestone:** Continued driving architectural planning and data preparation for the team capstone project.
